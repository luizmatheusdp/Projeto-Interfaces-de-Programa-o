2. Problema

Pessoas que precisam consultar informações básicas sobre municípios do Ceará precisam localizar os dados diretamente nas fontes do IBGE e compreender como realizar as consultas. Para usuários que não trabalham diretamente com programação ou com as bases do IBGE, esse processo pode dificultar o acesso e o reúso dos dados.

Nossa ação pretende reduzir essa dificuldade por meio de uma API simples e documentada para consulta de informações municipais.

3. Público externo

O público principal é formado por professores e produtores de conteúdo que utilizam dados públicos sobre municípios do Ceará.

Também poderão utilizar o produto jornalistas, estudantes da educação básica e integrantes de organizações ou coletivos que necessitem consultar informações municipais.

4. Produto

Será desenvolvida uma API pública para consulta de informações sobre municípios do Ceará utilizando dados públicos do IBGE.

No Marco 1, o produto mínimo será uma API funcional com pelo menos uma rota real, utilizando dados do IBGE e retornando uma resposta estruturada em JSON.
